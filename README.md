# Pulse

Тревел-агент для Большого Сочи: из одного сообщения собирает поездку целиком — перелёт, трансфер и отель — проверяет состыковки и оформляет заказ.

## Требования

- Python 3.11 или новее
- [uv](https://docs.astral.sh/uv/) (только для варианта 1)

## Запуск

Все команды выполняются из корня проекта. Выберите один из двух способов.

### Вариант 1: uv

1. Установите зависимости:
   ```bash
   uv sync
   ```
2. Создайте `.env` из примера и впишите ключи (`LLM_API_KEY`, `TRAVELPAYOUTS_TOKEN`; провайдер и модель настраиваются там же):
   ```bash
   cp .env.example .env
   ```
3. Запустите сервер:
   ```bash
   uv run uvicorn backend.main:app --reload
   ```

### Вариант 2: pip и requirements.txt

1. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv .venv
   ```
   Windows (PowerShell): `.venv\Scripts\Activate.ps1`, Linux и macOS: `source .venv/bin/activate`.
2. Установите зависимости:
   ```bash
   python -m pip install -r requirements.txt
   ```
3. Создайте `.env` (как в варианте 1) и запустите сервер:
   ```bash
   python -m uvicorn backend.main:app --reload
   ```

Страница будет доступна по адресу http://127.0.0.1:8000.

Проверить агента без веб-сервера можно в терминале (при варианте 2 вместо `uv run` пишите `python`):
```bash
uv run python -m docs.cli
```

`requirements.txt` дублирует список из `pyproject.toml`: при изменении зависимостей обновляйте оба файла.
Подробнее об устройстве агента — в [docs/AGENT.md](docs/AGENT.md).

## Тесты корзины

Серверные проверки: `python -m unittest discover -s tests -v`.

Браузерные проверки сообщений корзины: `python tests/browser_purchases.py -v`.
Для них дополнительно установите `python -m pip install playwright` и
`python -m playwright install chromium` в используемом виртуальном окружении.
Тесты запускают локальный сервер с временной базой, проверяют восстановление после
сбоев, сообщения об оплате и удалении, порядок ответов и переключение аккаунтов.
Реальная модель и рабочие данные приложения не используются.

Полный браузерный прогон восстановления запросов, включая тесты корзины:
`python tests/browser_network.py -v`. Проверяет остановку и обрыв потока, тайм-аут
заголовков и тела ответа, переключение аккаунта и неопределённый результат оплаты.

Обычные API-запросы ограничены 20 секундами вместе с чтением JSON. Ожидание ответа
агента останавливается после двух минут без новых данных; во время ответа доступна
кнопка остановки ожидания. Полученный текст сохраняется на экране, а кнопка
«Обновить чат» загружает состояние с сервера. Остановка ожидания не отменяет уже
выполненные сервером действия, поэтому операции оплаты автоматически не повторяются.

## Структура

- `backend/` — FastAPI-приложение (`main.py`) и агент (`backend/agent/`).
- `frontend/` — статичная веб-страница.
- `docs/` — документация агента и терминальный клиент (`docs/cli.py`).
- `evals/` — сценарии агента на настоящей модели и отчёты прогонов.
- `scripts/` — выгрузка отелей Сочи из OpenStreetMap.
- `pyproject.toml` — зависимости.

## Что умеет агент

- Собирает поездку целиком: перелёт туда и обратно, трансфер и отель, до трёх пакетов «Эконом /
  Оптимум / Комфорт» с одной итоговой суммой. Пакеты собирает код (`backend/agent/packages.py`),
  модель только объясняет выбор — суммы всегда сходятся.
- Сравнивает пакеты в рублях: «Комфорт дороже на 19 310 ₽ — 5★ вместо курорта, с завтраком».
- Ищет даты дешевле: сдвиг на ±3 дня по календарю цен Aviasales с той же длительностью.
- Проверяет поездку до оплаты и показывает маршрут по часам с проблемами у своего шага: ночной прилёт
  при заселении с 14:00, долгая дорога с ребёнком, лишняя ночь, хостел для семьи, превышение бюджета.
- Понимает «на майские», «на новогодние» по производственному календарю.
- Помнит пользователя между чатами (хранилище LangGraph): город вылета, состав семьи, предпочтения,
  прошлые заказы. Видно и стирается в профиле.
- Оформляет заказ только после кнопки «Оплатить» (interrupt LangGraph), без двойных заказов.
- Отвечает структурой (`AgentReply`): текст печатается по мере генерации, а рекомендация и подсказки
  следующих шагов приходят фронту отдельно.
- Устойчив к сбоям: повтор вызова модели и запасные модели (`LLM_FALLBACK_MODELS`), повтор сетевых
  инструментов, лимиты вызовов, фильтр инъекций во входе и в данных.

## Прогон сценариев

12 сценариев на настоящей модели: семья на майские, выходные, сдвиг дат, покупка с кнопкой, только
отель, мало данных, другой город, инъекция, нехватка бюджета, горы, память между чатами, «запомни».
Проверяется результат (состояние поездки, вызванные инструменты, формат и честность ответа),
а не дословный текст.

```bash
uv run python -m evals.run              # все
uv run python -m evals.run buy shift    # выбранные
uv run python -m evals.run --repeat 3   # стабильность
```

Отчёт — в `evals/results/`. Трассировка каждого хода в LangSmith включается переменными
`LANGSMITH_TRACING=true` и `LANGSMITH_API_KEY` (см. `.env.example`).

## Данные

Отели Большого Сочи — реальные объекты из OpenStreetMap: 1 358 гостиниц, гостевых домов, апартаментов,
хостелов и санаториев в шести районах (Адлер, Сириус, Хоста, Центр, Лазаревское, Красная Поляна).
Данные лежат в `backend/seed/sochi/hotels.json`, приложение в работе к OSM не обращается.

| Что | Откуда |
|---|---|
| Название, тип, адрес, координаты, звёзды, сайт, Wi-Fi | теги OpenStreetMap как есть |
| Район, расстояние до моря и аэропорта, первая линия, бассейн, что рядом | вычислено из геометрии OSM (границы районов, береговая линия, пляжи, станции, достопримечательности) |
| Дети, животные, парковка, завтрак, спа | в OSM почти не размечены — «нет данных», агент так и говорит |
| Дорога из аэропорта до отеля | маршрут по дорогам OSM (OSRM), с запасом на пробки |
| Перелёты | реальные недавние цены из кэша Aviasales (Travelpayouts), не бронь |
| Погода и температура моря | Open-Meteo: прогноз на 15 дней, дальше — как было в эти даты год назад |
| Праздники и длинные выходные | производственный календарь isdayoff.ru, с переносами |
| Фото | превью с сайта отеля или снимок места рядом из Wikimedia Commons (с автором и лицензией) |
| Цена, наличие, питание, условия отмены, цена такси | демо-модель в `backend/agent/adapters/hotels.py`: класс × тип × район × близость к морю × сезон |

У каждого отеля есть ссылка на объект в OSM, любой факт можно проверить на карте.
Красная Поляна (с Розой Хутор и Эсто-Садком) не имеет своей границы в OSM и выделяется правилом,
см. `backend/seed/sochi/meta.json`.

Обновить выгрузку (нужен интернет, ~1–3 минуты):

```bash
uv run python scripts/fetch_osm_sochi.py --refresh
```
