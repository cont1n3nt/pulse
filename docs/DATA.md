# Данные и локации

## Откуда данные

| Что | Откуда |
|---|---|
| Отели: название, тип, адрес, координаты, звёзды, сайт | OpenStreetMap, 1 358 объектов в шести районах |
| Район, расстояние до моря, первая линия, что рядом | вычислено из геометрии OSM |
| Дорога из аэропорта до отеля | маршрут по дорогам OSM (OSRM) с запасом на пробки |
| Перелёты | реальные недавние цены из кэша Aviasales (Travelpayouts), не бронь |
| Поезда | с `YANDEX_RASP_KEY` — настоящее расписание [Яндекс Расписаний](https://rasp.yandex.ru/): номер поезда, отправление и прибытие на ближайшую к отелю станцию, где он останавливается; цена — из API, если есть, иначе демо; места не проверяются, купить — на rzd.ru. Без ключа или при сбое API (пауза 10 минут) — демо-расписание: время в пути ориентировочное, цена купе условная. Станции и их координаты — настоящие |
| Погода и море | Open-Meteo: прогноз на 15 дней, дальше — те же даты год назад |
| Праздники | производственный календарь isdayoff.ru, с переносами |
| Фото | сайт отеля или Wikimedia Commons, с автором и лицензией |
| Цена и наличие отеля, питание, отмена, такси | демо-модель: класс × тип × район × море × сезон |

Источники подключены адаптерами (`backend/agent/adapters/`), контракт описан в `backend/agent/contracts.py`.
Чтобы подключить настоящий API отелей или билетов, нужно реализовать протокол из
`backend/agent/providers.py` и выбрать его в `PULSE_PROVIDERS` ([OSTROVOK.md](OSTROVOK.md)).

Данные об отелях и дорогах © [участники OpenStreetMap](https://www.openstreetmap.org/copyright), ODbL 1.0.
Погода — [Open-Meteo](https://open-meteo.com/) (CC BY 4.0). Фото из Wikimedia Commons — по лицензии в подписи.

## Локации

Код агента не знает названий городов и районов. Всё о месте лежит в папке `backend/seed/<id>/`:

- `location.json` — пишется руками: районы с описаниями для промпта и точками погоды, аэропорт, вокзалы
  и время до них (если есть поезда), часовой пояс, море и норма температуры воды, сезонность цен,
  тариф такси, подсказки для пустого чата и что выгружать из OpenStreetMap. Формат описан в
  `backend/agent/location.py`;
- `hotels.json` и `meta.json` — выгружает `scripts/fetch_osm.py <id>`: границы районов из OSM,
  расстояние до моря, дорога из аэропорта по OSRM, что рядом.

Как добавить город:

1. Создать `backend/seed/<id>/location.json` по образцу `sochi/location.json`: районы и их OSM-границы
   (relation id), аэропорт, часовой пояс, море (или `null`), поезда (или `null` — тогда только самолёт),
   сезонность и тариф такси.
2. `make seed LOCATION=<id>` — выгрузить отели из OpenStreetMap.
3. `PULSE_LOCATION=<id>` в `.env` и пересобрать: `docker compose up --build` (данные локации
   входят в образ; без Docker достаточно перезапустить).

Промпт, инструменты, погода, поезда, фото и подсказки в интерфейсе берут всё из локации. Один запуск
обслуживает одну локацию. Сценарии evals написаны для Сочи.
