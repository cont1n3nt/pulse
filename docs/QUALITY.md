# Качество: тесты, сценарии, метрики, наблюдаемость

## Юнит-тесты

`make test` (`tests/`) проверяют ядро без модели и сети:

- пакеты: суммы сходятся, уровни упорядочены, бюджет и «без хостелов с детьми» соблюдены, поезда приходят
  в день заезда, гибкие даты находят реальную экономию;
- проверку поездки: каждая несостыковка ловится своим кодом;
- перенос заказа и трансфер после покупки;
- локации: каждая описана полностью, промпт собирается из локации;
- контракты источников: пакеты, проверка и перенос заказа работают на «партнёрском» API в памяти;
- API: чужой чат и заказ не открыть, сбой базы — 503, перебор кода входа ограничен.

## Сценарии на настоящей модели

Сценарии проверяют результат, а не дословный текст: состояние поездки, вызванные инструменты, формат
и честность ответа. Их 24:

- основные: семья на майские, выходные, сдвиг дат, покупка с кнопкой, только отель, мало данных,
  другой город, инъекция, нехватка бюджета, горы, поезд, выбор района, память между чатами, «запомни»;
- запросы, которых агент не видел при настройке промпта: «тёплое море в ноябре», «Питер на выходные»,
  «Турция всё включено», «с собакой», «дороговато», лимит за ночь, «лыжи в июле», «удиви»;
- после покупки: перенос оплаченного заказа на день позже, трансфер к купленному отелю.

```bash
make evals                                        # в Docker
uv run python -m evals.run                        # локально: все
uv run python -m evals.run buy train --repeat 3   # выбранные, по 3 раза
```

В отчёт (`evals/results/<время>.md` и `.json`) попадают метрики:

- доля сценариев, доведённых до конца;
- сколько уточняющих вопросов до первого варианта;
- ходов и секунд до первого варианта;
- пакеты без ошибок состыковки;
- ходы с ошибкой;
- вызовов инструментов на ход.

Последний полный прогон, все 24 сценария, `claude-haiku-5-5`
([отчёт](../evals/results/20261029-080642.md)). Прогон расходует около 0,5 млн токенов.

| Метрика | Значение |
|---|---|
| Сценарии доведены до конца | 24/24, проверок 107/107 |
| Дошли до вариантов (остальные 7 — уточнение, другой город или страна, инъекция, «запомни», лыжи в июле) | 17/24 |
| Уточняющих вопросов до первого варианта, в среднем | 0,0 |
| Ходов до первого варианта, медиана | 1 |
| Секунд до первого варианта, медиана (от 9 до 39) | 27 |
| Пакетов без проблем состыковки | 42/42 |
| Ходов с ошибкой модели или инструмента | 0 |

Как агент отвечает на незнакомое (из прогонов):

- «Тёплое море в ноябре» — «тёплого моря в Сочи в ноябре не будет: обычно около 16 °C», и всё равно
  собирает поездку, предлагает даты на 2 140 ₽ дешевле или месяц с тёплым морем.
- «Питер на выходные» — «собираю поездки только в Большой Сочи… могу предложить похожий городской
  уикенд в Центре Сочи».
- «Лыжи в июле» — «снега для катания нет», предлагает Красную Поляну летом или лыжи зимой.
- «Дороговато» — «снизил бюджет примерно на 20% ниже прежнего Оптимума» и пересобирает поездку.

Прогоны находили проблемы, и каждая исправлена:

- «с собакой» уходило в пожелание вместо условия «с животными» — удобства передаются прямо в подбор;
- на «тёплое море» модель не знала нормы воды — нормы из локации есть в промпте;
- ход падал на 503 провайдера — вызов модели повторяется дважды;
- на «дороговато» модель иногда советовала Эконом вместо пересборки (1 раз из 3) — в промпте правило
  «дешевле без суммы — новый бюджет на 20% ниже», после правки 3/3 и 24/24;
- каждый подбор с самолётом ждал сравнения с поездом: три станции Яндекс Расписаний опрашивались
  по очереди, до 20 с на новых датах. Теперь параллельно и не дольше 4 с: медиана до первого варианта
  30 → 27 с, самый долгий сценарий 64 → 39 с.

Основной набор на других моделях: `gemma` — 12/12 ([отчёт](../evals/results/20261027-191256.md)),
`gpt-oss` — 9/12 ([отчёт](../evals/results/20261027-231612.md)). Эти прогоны были до сценариев с поездом,
выбором района и работы после покупки.

## Наблюдаемость

- **Логи** (`make logs`): по строке на каждый вызов модели (модель, секунды, токены, какие инструменты
  вызывает) и инструмента (ok или ошибка, время, аргументы), а также начало и конец хода с длительностью.
- **LangSmith**: впишите в `.env` `LANGSMITH_TRACING=true`, `LANGSMITH_API_KEY` и `LANGSMITH_PROJECT=pulse`,
  затем перезапустите сервис. Каждый ход станет деревом: промпт, ответ модели, вызовы инструментов с входом
  и выходом, токены и время.

Публичные трассы настоящих ходов агента (`claude-haiku-5-5`), открываются без входа в LangSmith:

  «Парковка в данных не указана».
- [«Нужен только отель в Хосте на 4 ночи с 5 декабря, нас двое, билеты купили сами»](https://smith.langchain.com/public/a93aaf03-cbb1-412c-a814-d89b7706c45c/r/01a1836d-bdda-7042-8f9a-3d875e0fa2c4?start_time=2026-10-28T16%3A52%3A49.754512Z),
